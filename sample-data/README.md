# sample-data — /tsa 示例数据

```
retail_daily_sales.csv            1096 行（2023-01-01 → 2025-12-31 日频）
make_sample_data.py               生成器（仅标准库，固定随机种子）
```

重新生成：

```bash
python sample-data/make_sample_data.py
```

## 推荐用法

```bash
/tsa sample-data/retail_daily_sales.csv
```

零参数即可跑通：时间列 `date`、目标列 `sales` 都能自动探测，频率推断为 `D`、周期 7、
默认预测步长 14。想显式指定：

```bash
/tsa sample-data/retail_daily_sales.csv --value-col sales --freq D --horizon 28 --name demo
```

## 表结构

| 列 | 类型 | 说明 |
|---|---|---|
| `date` | ISO 日期 | 时间列（无时区） |
| `region` | 文本 | **常量列**「华东」，用来触发无常量列检查 |
| `sales` | 整数 | 目标列：当日销量 |
| `unit_price` | 浮点(2位) | 客单价，缓慢上浮 |
| `is_promo` | 0/1 | 是否促销日（数值列但不是目标） |

## 刻意植入的结构

数据是按「能覆盖 /tsa 四个分析步骤」设计的，不是随机噪声。

**Step 1 — 质量检查**

| 现象 | 具体设定 |
|---|---|
| 连续缺失 | 2024-05-06 起 5 天（`sales` 为空，模拟系统故障） |
| 单点缺失 | 2024-10-03、2025-06-11 |
| 日历缺口 | 2024-08-15 整行不存在 |
| 重复时间戳 | 2025-04-02 两行（值差 4，模拟事后修正，需按均值聚合） |
| 乱序 | 1 对相邻行顺序颠倒 |
| 常量列 / 全空列 | `region` 全为「华东」；无全空列 |
| 预期评级 | `warn`（缺失 8/1096 = 0.73%、缺口 1 个、重复 1 个、乱序） |

**Step 2 — 平稳性与分解**

- 星期效应：周一/周二低（−62/−78），周六最高（+152）
- 年度周期：夏季峰（6 月，振幅 120）+ 年末购物季（11-11 与 12-21 两个高斯峰，振幅 150/210）
- 趋势：+0.09/天，三年累计约 +98
- 噪声：σ = 28
- 预期：周期 `m = 7`，趋势强度 ≈ 0.93、季节强度 ≈ 0.87，原序列非平稳 → `d = 1`（实测一致）

**Step 3 — 建模与回测**

- 强季节 + 趋势 + 可预测的年度形状 → 季节朴素法（RMSE ≈ 71）明显不如带季节项的模型
- 实测冠军：SARIMA（RMSE 53.8），ETS 54.0、Ridge 54.9 紧随，比最佳基线改善 ≈ 24%

**Step 4 — 异常与变点**

| 类型 | 位置 | 幅度 | 说明 |
|---|---|---|---|
| 点异常 | 2024-06-18 | +265 | 直播带货爆单 |
| 点异常 | 2024-11-11 | +240 | 双十一 |
| 点异常 | 2025-01-25 | −235 | 收银系统故障 |
| 点异常 | 2025-08-08 | +305 | 周年庆大促 |
| 水平漂移 | 2024-09-01 | +150 | 渠道导流 / 新增配送覆盖 |
| 水平漂移 | 2025-10-01 | −90 | 竞品在同商圈开业 |

实测：前 4 个点异常正好就是异常列表的 **前 4 名**（稳健 z = 20.8 / 15.7 / 14.7 / −13.9），
2 个水平漂移被准确识别为**仅有的 2 个**结构变点（2024-09-01 与 2025-09-30，跳跃量 +157 / −158）。

> 第二个漂移（−90）紧接年末购物季，季节回落与水平下移只有一两个月样本可分，
> 变点检测给出的幅度可能偏大。这是方法的固有限制，报告里会标注 `置信度=中` 且没有交叉验证。

## 已知的合理行为（不是 bug）

- `sales` 列在 2024-11-11 这样的促销日不会因为 IQR(1.5) 被判为异常值——整条序列的季节波动幅度本身就大。
  真正的点异常只在 **STL 残差** 上才显著，这也是 Step 4 用残差而不是原序列的原因。
- 变点检测在跨度 < 540 天的数据上会跳过年度谐波拟合（`cycle_removal: none`），
  本数据集跨度 1096 天，会走完整流程。
